# CONCEPT — 『TINY LUCK』非公式ファンMV

> 本作は八木海莉「TINY LUCK」（映画『GROTESQQQUE-グロテスク-』第三部『ノクターン～このグロテスクな夜に～』劇中歌）の
> **非公式ファンMV**です。公式映像ではありません。楽曲クレジットは末尾クレジットと README に明記します。

## Thesis（一文）
永遠生きる少女にとって「小さな幸運」とは、失われることを知りながら誰かと過ごした時間そのものであり、
その時間は滅びた世界の夜に、小さな星の結晶として残り続ける。

## Logline
人類が滅びた後の星夜。ワゴン車で旅する吸血鬼の少女は、限りある命の三人の少女たちと笑い、傷つき、
やがて来る別れを恐れながらも、共に過ごした一瞬一瞬を金色の草原に星屑として刻んでいく。
「きっと一瞬は永遠」——刹那は、覚えている限り永遠になる。

## 素材の読み（歌詞→映像）
- 「きっと一瞬は永遠」→ 母題：**小さな四芒星（Tiny Star）**。一瞬の光が結晶化して残る形。
- 「空に光る また一つ明かりが差す」→ 副歌のたびに夜空に星が一つ増える。最終副歌で星嵐になる（蓄積の可視化）。
- 「夜 照らすただ一つ」→ ワゴンの灯・掌の小さな星。世界でただ一つの灯。
- 「小さな傷」→ 金の糸で縫う傷跡モチーフ。傷は消えず、金で継がれる（金継ぎ）。
- 「側にいて いさせて」→ 文字が少女の**後ろ**に回り、歌詞より人が前に立つ構図（skill の fg レイヤー）。
- 『ノクターン』（吸血鬼・アヤメたち）→ 永遠を生きる者の孤独 vs 有限の命の同伴者たち。

## Master shapes / motifs
1. **四芒星（☆型スパーク）**：Tiny Luck の結晶。増えていく星＝積み重なる記憶。
2. **金色の草原の光点**：地上の星。記憶の結晶が降り積もった場所。
3. **紅金の腕リボン**：同伴者たちとの結び目。風で常に動く motion prop。
4. **ワゴンの灯**：「ただ一つ」の現実の灯。暖色の安全域。
5. **金の継ぎ目**：傷を隠さず継ぐ線（Chorus 2）。

## Character（要約、詳細は CHARACTER.md）
永遠を生きる吸血鬼の少女（オリジナル）：ash-silver 長髪、紅瞳、金の星髪飾り、深藍ヴィクトリアンドレス、紅金リボン。
同伴者は三人の人間の少女（オリジナル、主にシルエット/群像で登場）。実在人物・既存キャラの顔は描かない。

## Signature moments（8）
1. Intro：星1つからタイトル「TINY LUCK」が結晶化するタイトルリフ（0:00）
2. Chorus 1 頭：星のバーストと共に巨大歌詞の**後ろ**から少女が立つ（文字後ろヒーロー）

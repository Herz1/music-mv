  シルエット同伴者層で代替。次回生成後に該当ショット（s03/s11/s29/s32/s35）差替予定。

  bg_ruins / bg_road は次回追加予定。
- レンダラーは skill の WebGL/JIZURA エンジンではなく、同一原則（t の純関数、拍グリッド、
  レイヤー構造、残像エンド）を満たす決定的 Python 実装。Blender 3D は 2.5D で代替。
- 音源はユーザーが自リポジトリにアップロードしたものを使用。第三者への再配布は権利者の許諾が必要。
